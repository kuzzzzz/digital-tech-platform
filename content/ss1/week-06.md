# WEEK 6 — COMPUTER SOFTWARE

**Sub-topics:** Meaning of software · System software · Application software · Utility programs · Language translators · Software licensing and piracy

## Behavioural Objectives
By the end of the lesson, students should be able to:
1. define computer software and distinguish it clearly from hardware;
2. draw and explain the classification chart of computer software;
3. describe system software and its four components;
4. differentiate between a compiler, an interpreter and an assembler;
5. list and describe at least six utility programs;
6. distinguish between general-purpose and special-purpose application software;
7. explain software licensing types and the consequences of software piracy.

## Entry Behaviour
Students learnt hardware in Week 4 and use applications (WhatsApp, Word, browsers) daily.

## Instructional Materials
A computer with Windows/Linux installed, a genuine software CD or licence card, screenshots or a projector, chart showing software classification, an antivirus installation.

---

## PERIOD 1 (45 minutes)

### 6.1 Meaning of Software
**Software** is a set of coded **instructions (programs)** that tells the computer hardware what to do and how to do it. Software is **intangible** — it can be stored, copied and installed, but it cannot be touched.

| Hardware | Software |
|---|---|
| Physical and tangible | Logical and intangible |
| Can be damaged by shock, water, heat | Can be corrupted by viruses or bugs |
| Wears out over time | Does not wear out; becomes obsolete |
| Replaced when faulty | Repaired by debugging, patching or reinstallation |
| Manufactured | Developed/programmed |
| Example: keyboard, CPU | Example: Windows, MS Word |

### 6.2 Classification of Software

```
                    COMPUTER SOFTWARE
                           │
        ┌──────────────────┴──────────────────┐
   SYSTEM SOFTWARE                    APPLICATION SOFTWARE
        │                                     │
 ┌──────┼──────┬────────────┐        ┌────────┴────────┐
Operating  Utility  Language  Device  General-purpose  Special-purpose
 System   Programs Translators Drivers  (off-the-shelf)   (custom/bespoke)
```

### 6.3 System Software
Software that manages and controls the computer itself and provides a platform on which application software runs.

**(a) Operating System** — the master control program (treated fully in Week 8). Examples: Windows, macOS, Linux, Android, iOS.

**(b) Utility programs** — small housekeeping programs that maintain and optimise the system:

| Utility | Purpose |
|---|---|
| Antivirus | Detects, quarantines and removes malicious software |
| Disk defragmenter | Reorganises scattered file fragments to speed up access |
| Disk cleanup | Removes temporary and unwanted files to recover space |
| Backup and restore | Makes copies of data for recovery after loss |
| File compression | Reduces file size for storage/transfer (WinRAR, 7-Zip) |
| File manager | Organises files and folders (Windows File Explorer) |
| Disk partitioning | Divides a drive into logical sections |
| Screen saver | Prevents screen burn-in; provides basic privacy |
| Device manager | Monitors and configures connected hardware |

**(c) Language translators** — convert program code into machine language the CPU can execute:

| Translator | Converts | How it works |
|---|---|---|
| **Assembler** | Assembly language → machine language | Line-for-line translation of mnemonics |
| **Compiler** | High-level language → machine language | Translates the **entire program at once**, produces an executable file, reports all errors together, faster execution. Used by C, C++, Java |
| **Interpreter** | High-level language → machine language | Translates and executes **line by line**, stops at the first error, slower execution but easier to debug. Used by Python, BASIC, JavaScript |

**(d) Device drivers** — programs that enable the operating system to communicate with a specific hardware device (printer driver, graphics driver).

**(e) Firmware** — software permanently written into a hardware chip, e.g. **BIOS/UEFI**.

## PERIOD 2 (45 minutes)

### 6.4 Application Software
Programs written to help the **user** perform specific real-world tasks.

**(a) General-purpose (off-the-shelf) packages** — ready-made, sold to the public, used by many different people:

| Type | Purpose | Examples |
|---|---|---|
| Word processor | Typing and formatting documents | MS Word, Google Docs, LibreOffice Writer, WPS Office |
| Spreadsheet | Calculations, tables, charts | MS Excel, Google Sheets |
| Presentation | Slide shows | MS PowerPoint, Google Slides, Canva |
| Database management (DBMS) | Storing and querying structured data | MS Access, MySQL, Oracle |
| Graphics/design | Images and layout | CorelDRAW, Adobe Photoshop, GIMP, Canva |
| Web browser | Accessing the internet | Chrome, Firefox, Edge, Opera Mini |
| Media player | Playing audio and video | VLC, Windows Media Player |
| Communication | Messaging and meetings | WhatsApp, Zoom, Google Meet |
| Accounting | Business records | Sage, QuickBooks, Peachtree |

**(b) Special-purpose (custom/bespoke/tailor-made) software** — written for one organisation's specific need:
- A school's own result-processing and portal system.
- A bank's core banking application.
- The **JAMB CBT examination software**.
- INEC's result-transmission system.
- Hospital patient-records software.

| General-purpose | Special-purpose |
|---|---|
| Ready-made, buy and use immediately | Takes months to develop |
| Cheaper (cost shared among many buyers) | Expensive (one client bears the cost) |
| May contain unneeded features | Fits the organisation exactly |
| Well tested by many users | Errors may only surface in use |
| Support and tutorials widely available | Support depends on the developer |

**(c) Integrated packages / software suites** — several applications bundled to work together: Microsoft Office, Google Workspace, LibreOffice, WPS Office.

### 6.5 Software Acquisition and Licensing

| Type | Meaning |
|---|---|
| **Commercial/proprietary** | Bought with a licence; source code kept secret (Windows, MS Office) |
| **Freeware** | Free to use, but source code not released (Adobe Reader, Opera) |
| **Shareware** | Free trial for a limited period or with limited features, then payment required |
| **Open-source** | Free, and the source code may be studied and modified (Linux, LibreOffice, GIMP, Python) |
| **Subscription / SaaS** | Paid periodically and used online (Microsoft 365, Google Workspace, Adobe Creative Cloud) |

**Software piracy** is the unauthorised copying, distribution or use of licensed software. It is a criminal offence under Nigerian copyright law, enforced by the **Nigerian Copyright Commission**. Consequences include prosecution and fines, loss of updates and technical support, exposure to viruses hidden in cracked installers, system instability, and loss of revenue that would fund further software development in Nigeria.

### 6.6 Criteria for Selecting Software
Suitability for the task · Hardware compatibility (system requirements) · Cost and licensing terms · Ease of learning and use · Availability of support and training · Security and reliability · Upgrade path and vendor reputation · Portability across devices.

## EVALUATION — WEEK 6

### A. Objective Questions (1 mark each)
1. Software that controls the computer itself is called ______ software.
 (a) application (b) system (c) bespoke (d) integrated
2. Which translator converts the whole program at once?
 (a) Assembler (b) Interpreter (c) Compiler (d) Linker
3. Free software whose source code can be modified is called ______.
 (a) freeware (b) shareware (c) open-source (d) firmware
4. Which of these is a utility program?
 (a) MS Word (b) Disk defragmenter (c) Windows 11 (d) Chrome
5. The JAMB CBT examination program is an example of ______ software.
 (a) general-purpose (b) special-purpose (c) utility (d) system

**Answers:** 1(b) 2(c) 3(c) 4(b) 5(b)

### B. Theory Questions
1. Define computer software and state five differences between hardware and software. **(12 marks)**
2. Draw the classification chart of computer software. **(6 marks)**
3. Differentiate between a compiler and an interpreter in four ways. **(8 marks)**
4. Name five utility programs and state the function of each. **(10 marks)**
5. Distinguish between general-purpose and special-purpose software, giving two examples of each. **(8 marks)**
6. What is software piracy? State four of its consequences. **(6 marks)**

### C. Class Activity
Students list every application installed on their own phone, classify each as system or application software, and identify which are freeware, which are paid and which came pre-installed.

## TEACHER'S HELPER NOTES — WEEK 6
- **The classification chart is the spine of this lesson.** Draw it on the board first, before any explanation, and keep it there for both periods. Every new term you introduce should be pointed to on the chart. Students who can reproduce the chart can answer most examination questions on software.
- **Misconception 1:** students think "software" means only the things with icons on the desktop. Point out that Windows itself is software, the printer driver is software, and the program inside the ATM is software.
- **Misconception 2:** confusing the *operating system* with *utility programs*. The OS is the manager; utilities are the cleaners and maintenance staff.
- **The compiler-vs-interpreter difference is examined almost every year.** Give a memorable framing: *a compiler is a translator who reads the whole letter and hands you the finished translation; an interpreter stands beside you and translates sentence by sentence as the speaker talks.* Then add the consequence — the compiler tells you all your errors at once; the interpreter stops you at the first one.
- **Handle piracy honestly.** Cracked software is common and students know it. Rather than moralising alone, give the practical argument: cracked installers are the single most common source of the malware that wipes a student's project the night before submission. Then introduce the free legal alternatives — **LibreOffice, WPS Office, GIMP, Canva free tier, Google Docs** — all of which run on modest machines. This is genuinely useful advice in a Nigerian classroom.
- **If you have one computer only**, project or gather students round and open Task Manager (Ctrl+Shift+Esc) to show the number of programs running at once. It makes "software" concrete.
- **Time trap:** the application-software table is long. Explain word processor, spreadsheet, DBMS and browser thoroughly; let the rest be copied.
- **Preview Week 8** by ending the lesson with: *"Of all system software, one is the master. Next lesson we study it."*
