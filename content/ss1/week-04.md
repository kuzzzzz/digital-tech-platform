# WEEK 4 - COMPUTER HARDWARE

**Sub-topics:** Input devices . Output devices . Storage devices . System unit

## Behavioural Objectives
1. Identify common input and output devices
2. Distinguish between primary and secondary storage
3. Describe the function of the system unit components
4. State the uses of at least three peripheral devices

## Entry Behaviour
Students have seen computers at home or school and can name the monitor, keyboard and mouse.

## Instructional Materials
- Real computer system (desktop or laptop)
- Chart of hardware components
- Flash drive and external hard disk
- Projector (if available)

## PERIOD 1 (45 minutes)

### 4.1 Input Devices
An **input device** is any hardware component that allows a user to enter data and instructions into a computer.

Common examples:
- Keyboard
- Mouse
- Scanner
- Microphone
- Webcam
- Touch screen

> Note: Without input devices the computer cannot receive information from the outside world.

### 4.2 Output Devices
An **output device** presents processed data to the user.

Examples:
| Device     | Output type   |
|------------|---------------|
| Monitor    | Visual        |
| Printer    | Hard copy     |
| Speakers   | Sound         |
| Projector  | Large visual  |

### 4.3 Storage Devices
Storage devices keep data for later use.

- **Primary storage**: RAM (temporary, volatile)
- **Secondary storage**: Hard disk, SSD, flash drive, optical discs

## PERIOD 2 (45 minutes)

### 4.4 The System Unit
The system unit houses the main electronic components:
- Motherboard
- CPU (Central Processing Unit)
- Power supply unit
- Cooling fans
- Expansion slots

### 4.5 Peripheral Devices
Peripherals are external devices connected to the system unit.
Examples include printers, scanners, external drives and webcams.

## EVALUATION - WEEK 4

### A. Objective Questions (1 mark each)
1. Which of the following is an input device?
 (a) Monitor (b) Keyboard (c) Printer (d) Speaker
2. RAM is an example of
 (a) secondary storage (b) output device (c) primary storage (d) software
3. The brain of the computer is the
 (a) CPU (b) Monitor (c) Keyboard (d) Mouse
4. Which device produces hard-copy output?
 (a) Speaker (b) Monitor (c) Printer (d) Webcam
5. A flash drive is mainly used for
 (a) processing (b) storage (c) display (d) cooling
**Answers:** 1(b) 2(c) 3(a) 4(c) 5(b)

### B. Theory Questions

2. Differentiate between primary and secondary storage. **(4 marks)**
3. Draw and label a simple diagram of a desktop system unit. **(5 marks)**
